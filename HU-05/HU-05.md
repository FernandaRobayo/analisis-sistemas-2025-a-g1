# Historia de Usuario Frontend - HU-05: Gestión Completa de Clientes

## Descripción

Como administrador del sistema, quiero contar con una interfaz completa para la gestión de clientes, de forma que pueda registrar nuevos clientes, visualizar un listado de todos ellos, y tener la capacidad de editar o eliminar la información de cualquier cliente existente en el sistema.



## Definición de Ready (DoR)

* La historia está claramente entendida por el equipo de frontend.
* Se han definido los campos y validaciones requeridas para el registro y edición de clientes (Nombre, Teléfono, Estado: Activo/Inactivo).

## Definición de Done (DoD)

* La interfaz permite registrar un nuevo cliente con los campos: "Nombre", "Teléfono", y el estado "Activo/Inactivo".
* Se valida el campo "Nombre" como obligatorio.
* La interfaz muestra un listado de todos los clientes registrados, con sus datos principales.
* Cada cliente en el listado cuenta con botones para "Editar" y "Eliminar".
* La interfaz permite editar la información de un cliente existente y guardar los cambios.
* Se muestran mensajes claros de éxito (ej. "Cliente guardado", "Cliente actualizado", "Cliente eliminado") y error (ej. "Campo obligatorio", "Error al guardar").

## Tasks

* Definir y documentar los campos del formulario de cliente: Nombre, Teléfono, Estado (Activo/Inactivo).
* Implementar la estructura HTML/CSS del formulario de "Nuevo Cliente" y el botón "Guardar Cliente".
* Implementar los botones "Editar" en cada fila del listado y su lógica para precargar el formulario con los datos del cliente a editar.
* Implementar los botones "Eliminar" en cada fila del listado, incluyendo una confirmación y la lógica para consumir el endpoint de eliminación.
