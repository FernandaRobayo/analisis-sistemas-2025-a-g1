RF1: Registro de Datos Básicos de los Usuarios del Sistema

📌 Descripción:
Se requiere registrar los datos básicos de los futuros usuarios del sistema. Para ello, se deben ingresar los siguientes datos:
Nombre
Fecha de nacimiento
Correo electrónico
Tipo de documento
Número de documento
Teléfono

📌 Flujo:
Ingresar al formulario Registro de Personas.
Completar los datos solicitados.
Confirmar el registro.

📌 Precondición:
El usuario administrador debe estar autenticado.

📌 Postcondición:
Se verifica que la persona no haya sido registrada previamente.
